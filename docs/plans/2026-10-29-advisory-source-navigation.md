## Problem and chosen scope

The frozen 60-job pilot retained 45 metadata bundles but no searchable source. Execution-bound mapping is intentionally strict. Declared workflow source at a run head answers a different question and needs a distinct contract, not relaxed execution proof. Existing collector behavior is `packages/cli/src/advisory/collect.ts:72`; unsupported execution bundles prohibit sources at `packages/cli/src/advisory/contracts.ts:97`.

Implement a separate local-only source sidecar and explicit `advisory collect-source` / `advisory ask-source` commands. Reuse exact repository/run/attempt/head/path verification, immutable Git commit/tree/blob acquisition and the unchanged whole-file source guard (`collect.ts:24`, `contracts.ts:53`). Source references retain complete original bytes and original blob SHA; never hash a sanitized excerpt as the original blob. This increment intentionally leaves environment/credential-bearing workflows refused. It does not expand model preparation or execution mapping.

## Contract and acceptance

- `collect-source --repository owner/name --run ID --attempt N --workflow PATH --output DIR [--format json|markdown]` has no source-job selection or executed-job claim. It verifies the same repository/run/attempt/workflow/head-repository identities as collection, then stores a strict versioned `advisory-declared-source` artifact in `source-evidence.json` through the existing private fresh-operation store. Bound one workflow to 256 KiB and 10,000 lines; fail rather than truncate. Record scope `repository-at-run-head`, visibility, exact head/event/path/blob/full text/ranges, API version, fetchedAt, tool source SHA and digest. Strictly validate all retained fields, hashes and ranges on every read.
- `ask-source --input DIR ... --question TEXT --format json|markdown` reads at most 20 source documents locally, validates the same sensitive-query guard, and returns bounded lexical source excerpts with immutable citations, scope and limitations. Reuse the existing lexical scoring policy, without query-specific tuning against heldout questions. Deduplicate identical source ranges and reject conflicting snapshots. No job duration, execution classification, cache miss, causal claim or model response is fabricated. Text is rendered inertly.
- Existing collect/inbox/ask/compare/prepare/enrich readers keep their execution contracts. Source sidecars cannot enter execution arithmetic, cohorts or inference. Recovery for source commands points only to valid local source commands/fresh collection; no misleading inference preparation or inbox fallback.
- Regression tests precede implementation: supported non-push/matrix/unnamed source navigation while execution remains unsupported; altered repository/attempt/head/path/tree/blob/ranges/digest refused; environment/credential-bearing source refused unchanged; sensitive query never echoed; source-only prepare sends zero requests; safe rendering; stale/conflicting/oversize/unsafe-path input and output collision recover through valid fresh input/output.

Report admitted-document coverage, execution mapping unchanged, relevant cited matches with overall27/heldout18 denominators, false matches on nine no-match questions, precision with actual nonzero denominators, and all guard refusals. Reuse disclosed agent labels; this is a diagnostic rerun, not a fresh unseen/human-reviewed qualification. No model/time/savings claim.
